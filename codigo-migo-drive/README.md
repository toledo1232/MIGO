# NEXORA MOVE

Plataforma de movilidad que conecta pasajeros verificados con conductores
verificados, permitiendo recibir propuestas, negociar precios y realizar
viajes con herramientas de seguridad.

## Productos

- Aplicación móvil del pasajero.
- Aplicación móvil del conductor.
- Backend central.
- Panel administrativo web.
- Centro de seguridad y soporte.
- Aplicación administrativa móvil en una fase posterior.

## Tecnología principal

- Flutter y Dart.
- Python y FastAPI.
- PostgreSQL y PostGIS.
- Redis.
- Next.js, React y TypeScript.
- Servicios de mapas y geolocalización.
- Notificaciones en tiempo real.

## Estado

Proyecto en preparación inicial.

## Reglas de seguridad

- No almacenar contraseñas en texto plano.
- No guardar secretos dentro del código.
- No publicar claves de API.
- No utilizar información bancaria real durante el desarrollo.
- No modificar saldos sin movimientos contables.
- No realizar operaciones administrativas sin auditoría.
- Revisar y probar cada cambio antes de producción.
